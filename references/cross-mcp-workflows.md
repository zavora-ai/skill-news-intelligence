# News Cross-MCP Workflows

## News + PR: Brand Health
```
NEWS: get_news_sentiment(query: brand_name) → sentiment
PR: monitor_brand(name: brand_name) → detailed coverage
```

## News + CRM: Customer Context
```
NEWS: search_news(query: customer_company) → recent news
CRM: create_activity(subject: "News context for meeting")
```
